# models/retrieval 目录文档

## 目录概述

本目录存放 RSS-DA（检索条件化域适应）的检索子模块，提供原型检索与空间相似度图构建能力，为下游提示适配器提供正负原型及相似度先验。`__init__.py` 统一导出检索组件。

## 逐文件说明

### `__init__.py`

- **功能**：检索子模块的统一导出入口。
- **导出内容**：`PrototypeRetriever`、`SimilarityHeatmapBuilder`、`cosine_similarity_map`。

### `similarity.py`

- **功能**：空间相似度图与正负融合模块，计算图像特征与原型之间的余弦相似度并融合为空间先验。
- **主要类与函数**：
  - `cosine_similarity_map`：计算图像特征与原型之间的逐像素余弦相似度图，返回形状 [B, K, H, W]。
  - `SimilarityHeatmapBuilder`：核心模块，融合正负原型相似度得到空间先验。
    - `__init__`：初始化融合投影层与可学习温度，并设置正负融合权重。
    - `_fuse`（静态方法）：将多原型相似度按权重加权或取均值融合为单通道热图。
    - `forward`：计算正负原型相似度热图并融合为空间先验，返回包含相似度、热图、空间先验等字段的字典。

### `prototype_retriever.py`

- **功能**：原型检索模块，从原型库中检索与查询特征最相关的正负原型，用于条件化分割。
- **主要类与函数**：
  - `_weighted_average`：按权重对特征做加权和并做 L2 归一化。
  - `_entropy`：计算归一化权重的香农熵。
  - `_match_feature_dim`：通过截断或零填充将特征最后一维对齐到目标维度。
  - `PrototypeRetriever`：核心模块，基于原型库检索正负原型。
    - `__init__`：初始化原型库引用、检索数量与查询投影子模块。
    - `global_average_pool`（静态方法）：对查询特征做全局平均池化并 L2 归一化。
    - `_retrieve_single`：对单个查询向量从候选条目中检索 top-k 最相似原型。
    - `forward`：对批量查询特征检索正负原型并汇总为结果字典，包含原型特征、权重、原型向量及检索稳定性统计。
